💳✨ **CREDIT CARD FINANCIAL DASHBOARD**
Power BI | PostgreSQL | Data Analytics
🌟 PROJECT OVERVIEW
The Credit Card Financial Dashboard is an interactive and visually rich Power BI dashboard designed to analyze and monitor credit card transactions, customer behavior, and financial performance in real time.
This project demonstrates how raw transactional data stored in PostgreSQL can be transformed into meaningful insights using Power BI, enabling data-driven financial decision-making.
🎯 **OBJECTIVE**
To analyze credit card spending patterns
To track revenue, transactions, and customer segments
To identify high-value customers and risk areas
To provide clear, interactive financial insights for stakeholders
🛠️ TOOLS & TECHNOLOGIES USED
Power BI – Data visualization & dashboard creation
PostgreSQL – Database management & data storage
SQL – Data extraction, filtering, and transformations
DAX – Calculated measures and KPIs
📊 **KEY DASHBOARD FEATURES**
✔️ Total Revenue & Transaction Analysis
✔️ Monthly & Yearly Spending Trends
✔️ Customer Segmentation (Age, Gender, Category)
✔️ Card Type Performance (Silver, Gold, Platinum, etc.)
✔️ Merchant & Category-wise Spending
✔️ Interactive Filters & Slicers for Dynamic Analysis
📈 **INSIGHTS GENERATED**
Identified top-spending customer segments
Analyzed most profitable card categories
Tracked peak spending periods
Compared transaction volume vs revenue trends
Highlighted customer behavior patterns
🧠 **SKILLS DEMONSTRATED**
Data Modeling & Relationships
SQL Query Writing
Power BI Report Design
KPI & Measure Creation using DAX
Business-oriented Data Analysis
Dashboard Storytelling
🗄️ **DATA SOURCE**
Transactional data imported from PostgreSQL database
Structured tables representing:
Customer Details
Transaction Records
Card Types
Spending Categories


🚀 **HOW TO RUN THIS PROJECT**
Follow the steps below to successfully set up and run the Credit Card Financial Dashboard on your system.
🖥️ PREREQUISITES
Make sure the following tools are installed on your system:
PostgreSQL (Database)
Power BI Desktop
Basic knowledge of SQL (optional but helpful)
📂 **STEP 1**: SET UP THE DATABASE (PostgreSQL)
Open PostgreSQL (pgAdmin).
Create a new database (e.g., credit_card_db).
Import the provided dataset (.csv / .sql files) into the database.
Verify tables and data using SQL queries.

🔗 **STEP 2**: CONNECT POSTGRESQL WITH POWER BI
Open Power BI Desktop.
Click on Get Data → PostgreSQL Database.
Enter:
Server: localhost
Database: credit_card_db
Select required tables and click Load.

🧹 **STEP 3**: DATA CLEANING & TRANSFORMATION
Open Power Query Editor.
Clean and transform data:
Remove null or duplicate values
Format date & numeric fields
Rename columns for clarity
Click Close & Apply.

📊 **STEP 4**: BUILD & EXPLORE THE DASHBOARD
Open the .pbix file provided in the repository.
Review:
KPIs & Measures (DAX)
Charts & Visuals
Filters & Slicers
Interact with visuals to explore insights dynamically.

🔄 **STEP 5**: REFRESH DATA
Click Refresh in Power BI to update the dashboard with the latest database data.
Ensure PostgreSQL service is running before refresh.

📈 **STEP 6**: CUSTOMIZE & EXTEND
Add new KPIs or visuals
Modify SQL queries or DAX measures
Connect additional data sources
Apply themes for enhanced visuals
